# Моделирование нагрузки и авто-масштабирование сервисов высоконагруженной событийной платформы

## О проекте

Система обрабатывает большие потоки событий через брокер сообщений и цепочки воркфлоу-задач. При росте трафика узкие места такие как брокер, консьюмеры, сервис-витрина и модули фильтрации начинают деградировать.

Цель проекта — исследовать поведение событийной платформы под различными профилями нагрузки и построить подходы к автоматическому масштабированию её компонентов.

# План работы

1. Разведочный анализ данных
   - Подготовить стенд и сбор метрик.
   - Сгенерировать данные на разных сценариях нагрузки.
   - Провести EDA и выделить потенциальные признаки.

2. Первые ML-модели
   - Определить возможные постановки задачи и таргеты.
   - Выбрать метрики качества.
   - Обучить и сравнить базовые модели.

3. ML-сервис
   - Обернуть модель в сервис.
   - Реализовать минимальный backend и интерфейс для демонстрации.

4. Улучшение решения
   - Исследовать более сложные модели и признаки.
   - Попробовать разные подходы к масштабированию и их сравнению на стенде.

5. Нейросетевые и агентные подходы
   - Настроить LLM-агента для диагностики по логам и метрикам.
   - Попробовать скейлинг с помощью агента.

6. Финальные доработки
   - Доработать систему.
   - Провести итоговые эксперименты при разных сценариях нагрузки.
